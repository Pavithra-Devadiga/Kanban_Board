# 🗂️ Kanban Board

A simple and interactive **Kanban Board** web application built using **HTML, CSS, and JavaScript**.  
This project helps visualize tasks across different stages of completion using the classic Kanban workflow.

---

## 🌐 Live Demo

🔗 **View the live project here:**  
https://pavithra-devadiga.github.io/Kanban_Board/

---

## ✨ Features

- 📌 Three task columns:
  - **To Do**
  - **In Progress**
  - **Done**
- ➕ Add new tasks using an **Add button**
- ✏️ Tasks can be deleted
- 🖱️ Drag and drop tasks between columns
- 🎨 Clean and minimal user interface
- 📱 Responsive layout for different screen sizes

---

## 🛠️ Technologies Used

- **HTML** – Structure of the board  
- **CSS** – Styling and layout  
- **JavaScript** – Task creation and drag-and-drop functionality
